One-Time Firebase Setup

Follow these steps once to enable real-time sync for your whole team. Takes about 5 minutes. Firebase is free.

Step 1 — Create Free Firebase Project

1
Go to console.firebase.google.com → Click "Add project" → Name it (e.g. "fob-manager") → Disable Google Analytics → Create

Step 2 — Enable Realtime Database

2
In Firebase Console → Build → Realtime Database → Create Database → Choose any location → Start in Test mode (we'll secure it later)

Step 3 — Enable Authentication

3
In Firebase Console → Build → Authentication → Get started → Email/Password → Enable → Save
4
Go to Authentication → Users → Add user → Add email + password for each team member (e.g. ravi@company.com / password123)

Step 4 — Get Your Config Code

5
In Firebase Console → Project Settings (⚙️ gear icon) → General → scroll down → Your apps → Web app (</>) → Register app → Copy the firebaseConfig object

Step 5 — Paste Config Here

6
Paste your Firebase config JSON below and click Save. This is stored in your browser only.

🔒 Your config is stored locally in your browser. It is not sent anywhere except to Firebase (Google) which is the service you are setting up.
